# smart-support-classifier
Automated IT Ticket Triage &amp; Resolution Assistant is the strongest all-around title for a resume or job application
To speed up daily support triage, I wrote a lightweight Python script that automatically categorizes incoming user issues and suggests a quick troubleshooting response. Using Python and the OpenAI API, the script takes a raw ticket description and outputs the priority level, affected system, and a ready-to-send reply. Building this showed me how even a 20-line script using a well-structured system prompt can save hours of repetitive manual sorting.
